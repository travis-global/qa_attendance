      How publish works

      1. Enter your officer PIN below, then click Confirm publish all.
      2. The button disables immediately so the same push cannot be started twice.
      3. This browser prepares a delta of changed master data (students, lectures, audit, hostel, etc.).
      4. Data is sent to the publish worker only — the GitHub token never leaves the worker.
      5. Each file is verified on GitHub before this device is marked clean.
      6. If anything fails, the status line below explains the cause (PIN, worker URL, key mismatch, or network). You can try again after it finishes.
